# Security

Please report security issues to thedesignagent@borntall.com with "Security" in the subject line, rather than opening a public issue. Include steps to reproduce and the plugin or package version.

We'll acknowledge your report, keep you updated while we fix it, and credit you if you'd like once a fix is released. Please give us a reasonable chance to fix the problem before disclosing it.

This repository contains the plugin manifests and skills. The server it connects to is described in our [privacy policy](https://www.thedesignagent.ai/privacy) and [terms](https://www.thedesignagent.ai/terms).
